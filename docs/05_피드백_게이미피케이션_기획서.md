# 05. 피드백·게이미피케이션 기획서

목표: 매일 다시 열게 만들기. 단어 암기는 지루해지기 쉬우므로 "방금 한 행동에 바로 반응"과 "쌓이는 것이 눈에 보임" 두 가지를 준다.

## 1. 즉각 피드백

| 순간 | 소리 | 화면 |
|---|---|---|
| 카드 뒤집기 | 짧은 틱 | 카드가 Y축으로 회전 |
| 다음 카드 | — | 카드가 왼쪽으로 날아감, 새 카드가 살짝 커지며 등장 |
| 기억상자 담기 | 낮은 두 음 | 상자 버튼이 튀어 오르고 "기억상자에 담았어요" |
| 기억상자 탈출 | 올라가는 세 음 | "탈출! 3일 뒤에 다시 확인해요" |
| 게임 정답 / 오답 | 높은 두 음 / 낮은 버저 | 보기가 초록 / 빨강 |
| 목표 달성·최고 기록 | 팡파르 | 색종이 |

- 효과음은 설정에서 끌 수 있다. 음원 파일 없이 브라우저에서 합성한다.
- **발음이 가장 중요한 피드백**이다. 발음 버튼은 카드 화면 왼쪽 아래에 항상 있고, 한자 읽기 게임은 답을 고르면 정답 발음을 들려준다.
- "움직임 줄이기"를 켠 기기에서는 색종이를 띄우지 않는다.

## 2. 하루 목표와 연속 학습

- 홈 맨 위에 "오늘 12 / 30" 과 진행 막대. 목표는 새 카드 수만 센다.
- 목표를 채우면 축하 화면: 새로 학습·복습·상자에 담은 수, 오늘 얻은 경험치.
- 연속 학습일(🔥 N일 연속)을 홈 오른쪽 위에 둔다. 하루라도 목표를 못 채우면 0으로 돌아간다.
- 학습 알람: 정한 시각에 "오늘 18개 남았어요" 알림. 앱을 완전히 닫아 두었으면 다음에 열 때 알려 준다.

## 3. 기억상자 — 모르는 단어가 줄어드는 재미

- 상자 속 개수는 홈과 기억상자 화면에 늘 보인다. 탈출시키면 숫자가 줄어든다.
- 탈출한 단어는 3·7·21일 뒤에 확인하고, 세 번 통과하면 "완전 암기"로 넘어간다.
- 복습 카드는 주황 테두리, 탈출 확인 카드는 보라 꼬리표로 구분한다.

## 4. 게임 3종

문제는 기억상자 → 탈출 확인 중 → 학습한 단어 → 나머지 순으로 뽑는다. 틀린 단어는 결과 화면에서 한 번에 기억상자에 담을 수 있다.

| 게임 | 규칙 | 점수 |
|---|---|---|
| 스피드 퀴즈 | 60초 4지선다(설정한 방향대로 뜻 또는 일본어 고르기). 오답은 −3초 | 정답 10점 × 배수. 3연속마다 배수 +1, 최대 5배 |
| 짝 맞추기 | 일본어 카드와 뜻 카드 짝 찾기. 6쌍 → 8쌍 → 10쌍 3단계 | 쌍당 50점에서 군더더기 뒤집기·시간만큼 감점 |
| 한자 읽기 | 시험 問題1 형식. 한자 단어의 읽기를 4개 중에서 고르기, 10문제 | 정답 10점. 오답 보기에 장음·촉음·탁음 함정 |

## 5. 경험치·레벨·배지

- 경험치: 새 카드 2, 복습 1, 목표 달성 30, 게임은 한 판 최대 40·하루 최대 120.
  - 게임만 해서 레벨을 올릴 수 없게 상한을 둔다. 주된 보상은 학습이다.
- 레벨 칭호: 입문 → 도전자 → 실력자 → 고수 → 합격권 (5레벨마다).
- 배지:

| 묶음 | 배지 |
|---|---|
| 꾸준함 | 첫 목표 달성, 7일·30일·100일 연속 |
| 학습량 | 누적 500·1,000·1,500개, 전체 학습 완료 |
| 암기 | 상자 탈출 50개, 완전 암기 100개 |
| 게임 | 퀴즈 300점, 짝 맞추기 300점, 한자 읽기 만점 |

## 6. 기록 화면

- 학습 달력(날짜별 학습량), 누적 학습 수와 전체 대비 진행률, 레벨.
- 배지 목록(얻은 것과 진행률).
- 주간 랭킹: 같은 가입 암호를 쓰는 사람들끼리 이번 주 경험치 순위. Firebase 를 연결했을 때만 보인다.

## 7. 하지 않는 것

- 틀렸을 때의 벌점·생명 제한. 틀린 단어는 기억상자로 보내면 된다.
- 광고 시청 보상, 유료 아이템.
