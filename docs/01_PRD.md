# 01. PRD — JLPT N2 기출 단어 정복

작성일 2026-11-24 · 상태: v1 구현 완료

## 1. 한 줄 정의

2022년 이후 JLPT N2 문자·어휘 파트에 나온 단어와 N2 필수 단어를, 한자·읽기·뜻·예문·발음과 함께 하루 목표만큼 카드로 외우고, 모르는 것은 "기억상자"로 반복해서 끝내 외우게 만드는 모바일 웹앱.

## 2. 사용자와 상황

- JLPT N2를 준비하는 한국인 학습자, 그리고 같은 가입 암호를 공유하는 소규모 지인 그룹.
- 휴대폰으로 한 손 조작. 하루 10~30분, 매일 이어서 사용.
- 한자를 "읽지 못해서" 틀리는 경우가 많으므로 단어마다 한자의 한국 훈음과 음독·훈독을 함께 본다.

## 3. 범위

### v1에서 하지 않는 것

- **기출 문제 문장 원문 표시.** JLPT 시험 문제의 저작권은 일본국제교류기금·일본국제교육지원협회에 있고 2010년 이후 기출은 공식 공개되지 않는다. 앱에는 출제된 단어·읽기·회차·유형만 담고, 예문은 그 단어를 쓴 **직접 작성한 문장**을 싣는다.
- 문법·독해·청해 파트.
- 일본어 직접 입력(가나 타자) 문제. 한국 휴대폰에 일본어 자판이 없는 경우가 많다.
- 관리자 화면, 결제.

## 4. 핵심 흐름

1. 첫 실행 → 이름 + 가입 암호 입력 → 홈
2. 홈에서 "오늘 학습 시작" → (기억상자에 복습할 것이 있으면) 복습 → 새 카드 → 목표 달성 축하
3. 카드 앞면(한자 표기) → 두 번 터치 → 뒷면(읽기·뜻·한자 훈음·예문·기출 회차), 발음 버튼으로 듣기
4. 하단 메뉴: 학습 / 기억상자 / 게임 / 기록 / 설정

## 5. 성공 기준 (완료 판정)

- F1~F12가 휴대폰 화면 크기에서 실제로 동작한다.
- 발음 버튼을 누르면 일본어 음성이 나온다. 기기에 일본어 음성이 없어도 온라인 음성으로 나온다.
- 1일차에 상자에 담은 단어가 2일차 시작 시 새 단어보다 먼저 나온다 (`?debugDate=` 로 날짜를 바꿔 검증).
- 기출 수집 현황과 단어·한자 개수를 `data/report.md` 로 남긴다.

## 6. 결정한 사항

| 항목 | 결정 | 이유 |
|---|---|---|
| 기출 출처 | 웹에 공개된 복원 자료 | 공식 기출이 없다. 신뢰도는 `data/kichul_report.md` 에 회차별로 적는다 |
| 기본 단어장 | 공개 N2 단어 목록(JLPT 구 2급 기준 목록) + 기출에만 나온 단어 | 기출만으로는 300개 안팎이라 학습량이 모자란다 |
| 하루 목표 | 기본 30개, 최소 10개 | 일본어는 한자·읽기·뜻을 함께 외워 카드 한 장의 부담이 크다 |
| 발음 | 기기 내장 음성 → 없으면 온라인 음성 | 음성 파일 2,000여 개를 싣지 않고도 모든 기기에서 들리게 한다 |
| 한자 범위 | 단어장에 실제로 쓰인 한자 전부 | 급수표 대신 "이 단어를 읽는 데 필요한 한자"를 보여 준다 |
| 저장 | 기기 저장 기본, Firebase 설정 시 동기화·랭킹 | 설정값 없이도 바로 쓸 수 있어야 한다 |
