# 03. 화면 흐름도 및 와이어프레임

기준 화면: 휴대폰 세로 375×812. 한 손 엄지가 닿는 아래쪽에 조작 버튼을, 눈이 머무는 가운데에 카드를 둔다.

## 1. 화면 흐름

```
[가입/로그인] ──▶ [홈·오늘의 학습] ──▶ [카드 학습] ──▶ [목표 달성 축하] ──▶ 게임 / 20개 더 / 홈
                      │                    ▲
        하단 메뉴     ├─ [기억상자] ───────┘ (상자 지금 복습하기)
                      ├─ [게임 목록] ──▶ 스피드 퀴즈 / 짝 맞추기 / 한자 읽기 ──▶ [결과·틀린 단어]
                      ├─ [기록] 달력·배지·주간 랭킹
                      └─ [설정]
```

카드 학습 안의 순서: 기억상자 복습 → 탈출 확인 → 새 카드.

## 2. 카드 학습 (핵심 화면)

```
┌───────────────────────────────┐
│ ✕   새 카드 3 / 30    오늘 2/30 │  ← 진행 막대(복습은 주황, 새 카드는 보라)
│ ▓▓▓░░░░░░░░░░░░░░░░░░░░░░░░░ │
│ ┌───────────────────────────┐ │
│ │ [명사·する] [기출 2회]      │ │  ← 품사, 기출 횟수
│ │                           │ │
│ │          警 備            │ │  ← 앞면: 한자 표기 (설정 시 읽기도)
│ │                           │ │
│ │  두 번 터치하면 읽기와 뜻이 │ │
│ └───────────────────────────┘ │
│  [🔊 발음] [ 📦 모르면 기억상자 ] [↻ 뒤집기] │  ← 가운데 버튼이 가장 크다
│  [ 이전 ]   [        다음        ]        │
└───────────────────────────────┘
```

뒷면(두 번 터치 또는 뒤집기):

```
│          警 備              │  표기
│          けいび             │  읽기 (보라색)
│       경비, 경비하다         │  뜻
│ ┌─────────┐ ┌─────────┐    │
│ │警 경계할 경│ │備 갖출 비 │    │  한자: 한국 훈음
│ │음 ケイ    │ │음 ビ      │    │        음독
│ │훈 —      │ │훈 そな.える│    │        훈독
│ └─────────┘ └─────────┘    │
│ ─────────────────────────  │
│ (🔊) 夜間(やかん)は警備(けいび)が… │  예문 + 후리가나 + 예문 듣기  ※ "예문 보기" 켰을 때
│      밤에는 경비가 삼엄하다.   │
│ 22년 12월 · 24년 12월 · 한자읽기·표기 │  기출 회차와 유형
```

### 조작

| 조작 | 동작 |
|---|---|
| 카드 두 번 터치 / 뒤집기 버튼 / Space | 뒤집기 |
| 왼쪽으로 밀기 / 다음 / → | 다음 카드 (학습 처리) |
| 오른쪽으로 밀기 / 이전 / ← | 이전 카드 |
| 발음 버튼 / S | 단어 발음 듣기 |
| 예문 옆 스피커 | 예문 듣기 |
| 모르면 기억상자 / B | 상자에 담기 (다시 누르면 취소) |
| 기억상자 탈출 (복습 카드에서만) | 상자에서 빼고 3일 뒤 확인 |

뜻 → 일본어 방향일 때는 답이 드러나지 않도록 뒤집기 전에는 발음 버튼을 막는다.

## 3. 홈

```
│ 홍길동님, 안녕하세요        [🔥 3일 연속] │
│ 오늘의 학습                              │
│ ┌──────────────────────────────┐        │
│ │ 오늘 목표      12 / 30         │        │
│ │ ▓▓▓▓▓░░░░░░░                  │        │
│ │ 기억상자 복습 5개를 먼저…      │        │
│ │ [      이어서 학습하기      ]  │        │
│ └──────────────────────────────┘        │
│ [누적 학습 120] [기억상자 8] [탈출 14]   │
│ Lv.3 입문  ▓▓▓░░  40 / 132 XP           │
│ 📦 지금 범위에 남은 새 카드 1,940개      │
│ [학습] [기억상자] [게임] [기록] [설정]   │
```

## 4. 기억상자

- 탭 2개: "상자 안 N" / "탈출 확인 중 N".
- 줄마다: 발음 버튼 · 표기 + 읽기 · 뜻 · (담은 날, 복습 횟수 / 다음 확인까지 남은 날) · 탈출 버튼.
- 맨 위 "상자 속 N개 지금 복습하기".

## 5. 게임

- 목록: 게임 3종 카드(이름·설명·최고 기록) + 오늘 얻은 게임 경험치 막대.
- 진행 화면 공통: 위쪽에 그만하기·진행(시간 또는 문항)·점수, 가운데 문제 카드, 아래쪽 보기 버튼.
- 결과: 점수, 얻은 경험치, 최고 기록, 틀린 단어 목록과 "기억상자에 담기".

## 6. 설정 (위에서부터)

1. 하루 목표 (10·20·30·50·100, 직접 입력)
2. 맞추는 방향 / 새 카드 순서
3. 학습 범위 (N2 전체 / 기출 단어만 → 기출 연도) / 품사 / 남은 새 카드 수
4. 발음: 자동 재생, 속도, 들어 보기(기기에 일본어 음성이 있는지 안내)
5. 학습 알람
6. 예문 보기 / 앞면에 읽기 표시 / 효과음
7. 계정(이름, 동기화 상태, 로그아웃), 조작법 다시 보기

## 7. 접근성·표시 원칙

- 일본어 글자에는 `lang="ja"` 를 붙여 일본어 글꼴로 그린다(한국어 글꼴로 그리면 한자 모양이 달라진다).
- 후리가나는 `<ruby>` 로 표시한다.
- 버튼은 44px 이상, 다크 모드와 "움직임 줄이기" 설정을 따른다.
