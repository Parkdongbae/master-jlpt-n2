# 02. 핵심 로직·규칙 명세서

화면과 저장소가 같은 규칙을 쓰도록 계산 기준을 한곳에 정한다. 구현은 `src/engine/engine.ts`(순수 함수), 검증은 `src/engine/engine.test.ts`.

## 1. 학습일

- 하루는 **새벽 4시**에 바뀐다. 밤 1시에 공부해도 전날 기록이다.
- 주간 랭킹의 한 주는 월요일에 시작한다.
- 주소 뒤에 `?debugDate=2026-11-25` 를 붙이면 그 날짜로 동작한다(검증용).

## 2. 카드 상태

| 상태 | 뜻 | 바뀌는 때 |
|---|---|---|
| (없음) | 아직 안 본 새 카드 | — |
| `l` 학습함 | 보고 넘긴 카드 | 새 카드를 넘김 |
| `b` 기억상자 | 모르는 단어 | "모르면 기억상자" 버튼 |
| `c` 탈출 확인 중 | 상자에서 뺀 뒤 확인 복습 대기 | "기억상자 탈출" 버튼 |
| `d` 완전 암기 | 확인 복습 3번 통과 | 21일째 확인 통과 |

## 3. 하루 세션의 순서

1. **복습 줄**: 기억상자 카드(오래 담긴 순) → 탈출 확인일이 된 카드. 최대 100장. 오늘 담은 카드와 오늘 이미 복습한 카드는 빠진다.
2. **새 카드 줄**: 설정 범위에 맞는 안 본 카드를 `목표 − 오늘 본 새 카드` 만큼.
3. 목표를 채우면 축하 화면. "20개 더 공부하기"로 이어 갈 수 있다.

하루 목표가 세는 것은 **새 카드 수**뿐이다. 복습은 목표와 따로 센다.

## 4. 기억상자와 탈출

- 상자 안 카드는 다음 학습일부터 **매일** 맨 먼저 나온다. 넘겨도 상자에 남는다.
- 오늘 담은 카드는 같은 카드에서 버튼을 다시 누르면 취소된다.
- 복습 때 외웠으면 "기억상자 탈출". 그 뒤 **3일 → 7일 → 21일** 간격으로 확인 복습이 나온다.
  - 확인 때 그냥 넘기면 통과 → 다음 단계. 세 번 통과하면 완전 암기.
  - 확인 때 다시 상자에 담으면 처음부터.

## 5. 새 카드가 나오는 순서

- **기출 많은 순(기본)**: 기출 회차 수가 큰 단어부터. 같은 횟수 안에서는 사용자 이름으로 섞은 고정 순서(사람마다 다르고, 같은 사람에게는 매번 같다).
- **무작위**: 사용자별 고정 섞기.

### 범위 필터

| 설정 | 규칙 |
|---|---|
| 학습 범위 = N2 전체 | 모든 단어 |
| 학습 범위 = 기출 단어만 | 고른 연도 중 한 번이라도 출제된 단어 |
| 품사 | 고른 품사에 속한 단어 (최소 1개는 선택) |

## 6. 기출 분석 기준

- 대상: 2022년 7월 ~ 2026년 7월 N2 문자·어휘 파트(問題1~6), 9개 회차.
- 한 문항에서 세는 단어:

| 유형 | 세는 단어 |
|---|---|
| 한자읽기(問題1), 표기(問題2) | 밑줄 단어 |
| 단어형성(問題3) | 정답을 넣어 완성된 말 |
| 문맥규정(問題4) | 정답 어휘 |
| 유의표현(問題5) | 밑줄 어휘와 정답 어휘 각각 |
| 용법(問題6) | 제시 어휘 |

- 단어는 사전형으로 맞춘다(険しかった → 険しい).
- **기출 횟수 = 그 단어가 나온 회차 수.** 한 회차에 두 유형으로 나와도 1회.
- 단어장과 잇는 순서: 표기+읽기 일치 → 표기 일치 → (가나 표기일 때) 읽기 일치. 못 이은 단어는 `data/extra_words.json` 에 뜻·예문을 붙여 단어장에 넣는다.

## 7. 발음 규칙

- 단어는 **읽기(가나)** 를 음성에 넘긴다. 한자 표기를 넘기면 紅葉을 "もみじ"로 읽는 식의 오독이 생긴다.
- 접사의 물결표(〜)는 읽지 않는다.
- 예문은 후리가나 표기를 걷어 낸 원문을 넘긴다(문장은 한자째 읽는 편이 억양이 자연스럽다).
- 속도: 보통 0.9배, 천천히 0.6배.
- 음성 선택: 기기의 일본어 음성 중 이름에 natural·neural·enhanced·premium·google 이 든 것을 먼저 쓴다.
- 일본어 음성이 하나도 없으면 온라인 음성으로 읽는다. 그것도 실패하면 "발음을 재생하지 못했어요" 안내를 띄운다.
- 자동 재생은 일본어가 앞면일 때만 한다(뜻→일본어 방향에서는 답을 알려 주게 되므로).

## 8. 경험치와 레벨

| 행동 | 경험치 |
|---|---|
| 새 카드 1장 | 2 |
| 복습 1장 | 1 |
| 하루 목표 달성 | 30 |
| 게임 | 한 판 최대 40, 하루 합계 최대 120 |

- 레벨 1 → 2에 100, 그 뒤로 필요량이 15%씩 늘어난다.
- 칭호는 5레벨마다: 입문 → 도전자 → 실력자 → 고수 → 합격권.
- 연속 학습일: 목표를 달성한 날이 이어진 일수. 오늘 아직 못 채웠으면 어제까지를 센다.

## 9. 한자 읽기 게임의 오답 만들기

1. 정답 읽기를 살짝 바꾼 것을 최대 2개: 장음(しょう↔しょ), 촉음(っ 빼기), 탁음(か↔が) — 실제 시험의 함정과 같은 종류.
2. 모자라면 길이·첫 글자·끝 글자·품사가 닮은 다른 단어의 읽기로 채운다.
3. 같은 표기의 다른 올바른 읽기는 오답으로 쓰지 않는다.
